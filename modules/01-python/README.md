## What This Module Demonstrates

- **Core language fluency** — data structures, control flow, exception handling, file I/O
- **Object-Oriented Programming** — class hierarchies modeling insurance entities (Contractor, Policy, Claim, RiskAssessment)
- **Generators & iterators** — lazy data processing patterns for large NovaBuild datasets
- **Decorators & context managers** — production patterns for logging, timing, resource management
- **Type hints & docstrings** — code that a code-review team would accept without pushback
- **Testing basics** — pytest patterns for validating business logic
